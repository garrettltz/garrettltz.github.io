Game Development Project

Root 66

Root 66 is a collaborative game development project created in Unity. Players operate a mobile smoothie café, preparing root vegetable smoothies while driving down the highway and delivering each order to the correct customer before time runs out.

Role Game Designer
Project Type Collaborative Game Project
Focus Gameplay Design and Iteration

Project Overview

Players control a moving smoothie café while preparing customer orders. The objective is to select the correct ingredients, blend each smoothie, and deliver it when the matching customer vehicle is nearby.

Controls

  • W: Accelerate
  • S: Brake
  • A and D: Steer
  • Mouse: Drag ingredients into the blender
  • Click: Blend and deliver smoothies

My Contribution

As a Game Designer, I collaborated with the development team to design gameplay mechanics, balance the player experience, and iterate on game systems through testing and feedback. I worked closely with programmers and artists throughout development to help refine the overall gameplay.
