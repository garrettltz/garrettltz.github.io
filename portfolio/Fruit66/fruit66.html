Game Development Project

Fruit 66

Fruit 66 is an award-winning game jam project where players operate a mobile smoothie café while driving down a busy highway. Players prepare smoothie orders, blend ingredients, and deliver drinks to the correct customers while avoiding mistakes.

Role Game Designer
Project Type Game Jam
Focus Gameplay Design and Iteration
Play the Game Back to Projects

Project Overview

Players control a moving smoothie café using the keyboard while preparing customer orders with the mouse. The goal is to select the correct ingredients, blend each smoothie, and deliver it to the matching customer vehicle.

Controls

  • W: Accelerate
  • S: Brake
  • A and D: Steer
  • Mouse: Drag ingredients into the blender
  • Click: Blend and deliver smoothies

My Contribution

I worked as a game designer and helped shape the gameplay flow, player interactions, and overall experience. I also contributed to testing and iteration during the rapid development process.
